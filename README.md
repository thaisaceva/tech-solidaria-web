# 🌐 ONG Tech Solidária — Plataforma Web Inclusiva

Plataforma institucional desenvolvida para a **ONG Tech Solidária**, com foco em promover a inclusão digital e a sustentabilidade no descarte de e-lixo.

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**: Estruturação acessível seguindo diretrizes da WCAG 2.1 AA.
- **CSS3 Moderno**:
  - **Design System**: Tokens modulares e variáveis globais (`:root`).
  - **CSS Grid (Macro Layout)**: Malha de 12 colunas responsiva.
  - **Flexbox (Micro Layout)**: Alinhamento de navegação, cards e formulários.
  - **Transições e Animações**: Menu mobile expansível com `max-height`, `opacity` e `transform`.
